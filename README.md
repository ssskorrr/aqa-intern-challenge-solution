Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Перед первым запуском установите браузер:
```shell
npx playwright install chromium
```

Также доступны команды `npm test` и `npm run test:headed`.

Изменения
---------

Исходный код задания: https://github.com/uchiru/aqa-intern-challenge

- Кнопка открытия находится по `data-test` на странице; элементы открытого
  виджета ищутся внутри его панели, без зависимости от внешней обертки типографики.
- Список популярных статей возвращается как Locator вместо моментального
  снимка через `all()`. Клик ожидает появления первой статьи.
- Заголовок возвращается как Locator и проверяется через `toHaveText`,
  который ожидает обновления интерфейса.
- Добавлен ровно один тест: открытие популярной статьи и проверка ее заголовка.
- При падении сохраняются скриншот и trace даже без повторного запуска.

Результаты проверки
-------------------

12 октября 2026 года исходные два теста и итоговые три теста были запущены
в Chromium. Все завершились ошибкой `page.goto: net::ERR_CONNECTION_CLOSED`
при переходе на https://uchi.ru, до загрузки виджета. Та же ошибка получена
в установленном Chrome и встроенном браузере. Успешный прогон на живом сайте
не подтвержден; актуальность CSS-селекторов и совпадение заголовка статьи
с подписью в списке требуется проверить после восстановления доступа.

Отдельная локальная диагностическая проверка Page Object на контролируемой
HTML-странице с задержками отрисовки прошла: открытие панели, ожидание статьи,
переход к статье и ожидание заголовка поддержки. Это проверяет механику
ожиданий, но не заменяет E2E-прогон на uchi.ru. Диагностическая страница
не входит в сдаваемый набор тестов. `git diff --check` также выполнен.
